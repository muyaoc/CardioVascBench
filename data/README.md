# Data Description

[中文版](./README_ZH.md)

This directory contains the data used by the CardioVascBench cardiovascular and cerebrovascular disease benchmark for large language models.

## Data Download

The datasets required for evaluation are available on the OpenI community platform:

- **Download**: [CardioVascBench Dataset](https://openi.pcl.ac.cn/explore/datasets/cindyc/CardioVascBench)

After downloading, extract or place the data in the corresponding locations described below.

## Directory Structure

- `source_data/`: Original generated case data (such as `source_data/source_data_public.json`).
- `llm_eval_data/`: Cleaned and standardized evaluation datasets (such as `eval_data/public_diagnosis_eval.json`).
- `llms_answers_data/`: Diagnostic answers generated by the models being evaluated.
- `llms_answers_data_generator.py`: Script for calling model APIs and generating answer data.
